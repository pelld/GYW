# Goodyear Welt — interactive visual guide

A detailed, mobile-friendly GitHub Pages explainer covering the anatomy, construction, repair, history and terminology of Goodyear-welted footwear.

## What is included

- Interactive exploded shoe anatomy
- Two-seam explanation (inseam vs outsole stitch)
- Eight-step construction sequence
- 270°, 360°, storm/split-reverse and closed-channel details
- Comparisons with Blake, cemented, hand-welted and stitchdown construction
- Historical timeline with primary patent sources
- Resole sequence
- Identification guide and common misconceptions
- Filterable glossary
- Five-question quiz

## Files

- `index.html` — page content and SVG diagrams
- `styles.css` — layout, typography and responsive design
- `script.js` — interactions, comparison panel, glossary and quiz
- `.nojekyll` — tells GitHub Pages to serve the static files directly
